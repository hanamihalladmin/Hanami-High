# Boutique animated items

Selected Hanami Boutique cosmetics intentionally animate in the storefront preview while most catalog items remain static for contrast and readability.

Current animated products include Petal Drift, Petal Shower, Star Spark, Starlight Trail, Bubble Pop, Firefly Drift, Arcade Bloom, Midnight Shrine, Aurora Mist, Moonlit Koi Orbit, Starlight Sprites, Sakura Drift Halo, Crystal Bloom Frame, Aurora Wing Frame, and Gilded Moon Frame.

Animation is decorative only and does not change ownership, pricing, rarity, or Petal behavior. Storefront motion is disabled by `prefers-reduced-motion: reduce`.
