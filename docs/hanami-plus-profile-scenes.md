# Hanami+ Living Profile Scenes

Living Profile Scenes are alternate rooms attached to a single Hanami character profile. They do not create extra characters, accounts, or a second profile system.

## Included rooms

- Music Room
- Photo Wall
- Journal
- Gaming Room
- Portfolio
- Friends Page
- Seasonal Room

## Visibility

A scene can never be more public than the character's published profile.

- `inherit`: uses the existing published-profile visibility rules.
- `friends`: requires the viewer's active character to be an accepted friend in addition to normal profile visibility.
- `private`: only the owning account can read the scene.

Unpublished scenes are owner-only drafts. Published scenes remain visible according to their privacy rules even if Hanami+ later expires.

## Hanami+ boundary

An active Hanami+ entitlement is required to initialize, edit, decorate, publish, unpublish, or rearrange scenes. Previously published scenes and saved scene decorations remain attached to the character after Hanami+ expires.

## Scene content

Each scene has its own background, accent, layout, title, description, and free-positioned items. Room-specific item palettes cover music, photos, journal cards, games, portfolio projects, friend cards, seasonal decorations, notes, images, links, counters, and buttons.
