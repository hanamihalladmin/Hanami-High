# Post-launch SpaceHey access/date cleanup

Acceptance scope:

- Public website uses a contained SpaceHey-style canvas rather than full-width bands.
- Public navigation stays within the same site width as page content.
- Hanami public palette is navy, sage, ivory/white, and dusty rose.
- Student/Faculty portal rail uses the same Hanami palette.
- RSS feeds and network status are removed from public navigation and gated to Administration/Owner accounts.
- Activities navigation opens the real Campus Life/Activities destination.
- Public club pages never expose officer/admin editing tools.
- Campus event feeds use the 2006 Hanami roleplay clock instead of the real 2026 clock.
- Japanese-script translations/branding are absent from website source and event titles.
- CI blocks Japanese-script UI regressions and missing exported routes.
